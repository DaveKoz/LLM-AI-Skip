# LLM-AI-Skip

This repo is a public, shareable collection of Markdown documents for developers building with Skip tools. There are a lot of little tweaks required to make everything run and compile correctly in Xcode so the Android version builds. The goal is to crowdsource these tips and keep them organized for everyone.

## Table of Contents

Documents are organized into the following folders:

- **[guides/](guides/)** — Step-by-step setup and workflow documentation
- **[troubleshooting/](troubleshooting/)** — Common errors and their solutions
- **[examples/](examples/)** — Sample configurations and reference material

## Contributing

We welcome contributions! If you have a tip, fix, or new document to share:

1. **Fork** this repository
2. **Clone** your fork locally
3. **Create a branch** for your changes
4. **Add or edit Markdown files** and commit your changes
5. **Push** to your fork
6. **Open a Pull Request** back to this repo with a clear description of what you added or changed

All documents live in this repo as Markdown files so they are easy to browse, search, and maintain. Small fixes and new guides are equally appreciated.

## Releases

We tag releases to track changes across the document collection. Each release notes which documents were added, updated, or removed so you can see what is new since the last version. Check the [Releases](../../releases) page for the latest tag and changelog.
